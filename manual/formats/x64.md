# X64 — extended D64

X64 is an old VICE-specific format: a regular disk image with a 64-byte header prepended. The header carries metadata (drive type, image type, side count, etc.) that the bare D64 byte stream doesn't.

## Detection

A file is treated as X64 when it starts with the header signature `$43 $15 $41 $64` **and** the bytes after the 64-byte header have the size of a known image. The `.x64` extension alone isn't enough — a renamed D64 still opens as a D64.

## What you can do

The editor strips the header on open and works on the image behind it — everything that applies to a [D64](d64.md) applies here.

## Saving

The header is **not** written back: the tab is renamed to `.d64` on open, and saving produces the plain image.

Current VICE versions open plain D64, so dropping the header loses nothing for normal use.
