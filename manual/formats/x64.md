# X64 — extended D64

X64 is a VICE-specific format: a regular D64 with a 64-byte header prepended. The header carries metadata (drive type, image type, side count, etc.) that the bare D64 byte stream doesn't.

## What you can do

The editor reads X64 transparently — it strips the header on open, treats the rest as a standard D64, and re-attaches the header on save (if you came in via `.x64`).

Most modern VICE versions accept plain D64 too, so X64 is rarely encountered today. The format is still useful if you want VICE-specific metadata to survive.

## Saving

If you opened `.x64`, **Save** writes `.x64` with the same header. Use **Save As** to drop the header and save as plain `.d64`.
