# D71 — 1571 disk image

A D71 is a double-sided 1571 floppy. Layout is the same as D64 for side 1 (tracks 1-35); side 2 occupies tracks 36-70 with its own BAM block.

## Sizes

| Tracks | Bytes | With error bytes |
|---|---|---|
| 70 | 349,696 | 351,062 |
| 80 | 399,360 | 400,832 (rarely seen) |

The 70-track size is the standard. 80-track D71s are a speeder-DOS extension.

## Geometry

- **Tracks**: 70 (35 per side)
- **Sectors per track**: same per-side pattern as D64 (21 / 19 / 18 / 17)
- **Directory track**: 18 (side 1, just like D64)
- **Extra BAM**: T53 stores the side-2 BAM extension (a 1571-specific block)
- **Default file interleave**: 6 (faster than D64's 10 thanks to the 1571's two-sided head)
- **Default dir interleave**: 5

The directory chain starts on side 1 just like D64; side 2 contributes only free-block accounting via its BAM block.

## What you can do

Same as D64 — full read/write, every editor feature applies.

When **Validate** rebuilds the BAM, it also rebuilds the side-2 BAM extension at T53. The View BAM heat map shows both sides in a single concentric strip.

## JiffyDOS interleave

The JiffyDOS V6 manual specifies different interleave defaults for 1571s than the stock ROM:

- **Stock 1571**: file 6, dir 5
- **JiffyDOS 1571**: file 4, dir 4

Both are available under **Options → Set Interleave**. The editor's default new D71 uses the stock values.

## Sub-directories

None. Flat directory like D64.

## Saving

Writes the natural size (349,696 bytes). 80-track speeder variant supported but rarely seen.
