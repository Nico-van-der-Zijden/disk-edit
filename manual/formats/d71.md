# D71 — 1571 disk image

A D71 is a double-sided 1571 floppy. Layout is the same as D64 for side 1 (tracks 1-35); side 2 occupies tracks 36-70, with its BAM bitmaps on track 53.

## Sizes

| Tracks | Bytes | With error bytes |
|---|---|---|
| 70 | 349,696 | 351,062 |
| 80 | 393,216 | 394,752 (rarely seen) |

The 70-track size is the standard. Tracks 71-80 of an 80-track image lie outside the BAM.

## Geometry

- **Tracks**: 70 (35 per side)
- **Sectors per track**: same per-side pattern as D64 (21 / 19 / 18 / 17)
- **Directory track**: 18 (side 1, just like D64)
- **Side-2 BAM**: free counts at T18/S0 `+$DD`, bitmaps at T53/S0. As on a real 1571, the whole of track 53 is allocated, so a freshly created D71 reports **1328 blocks free**.
- **Default file interleave**: 6
- **Default dir interleave**: 3

The directory chain starts on side 1 just like D64; side 2 contributes only free-block accounting via its BAM.

## What you can do

Same as D64 — full read/write, every editor feature applies.

When **Validate** rebuilds the BAM, it also rebuilds the side-2 bitmaps on T53.

## Interleave presets

**Options → Set Interleave** offers these file-interleave presets for D71:

- **1571 Standard** — 6 (the default)
- **1571 Optimized** — 5
- **1541 Compatible** — 10
- **1571 JiffyDOS** — 4

## Sub-directories

None. Flat directory like D64.

## Saving

Writes the image at the size it was opened or created with.
