# D81 — 1581 disk image

A D81 is a 3.5" 1581 floppy. Compared to D64 it has more capacity (3,200 sectors of 256 bytes ≈ 800 KiB), a single sector size, and **CBM sub-partitions** — a primitive way to carve up the disk into pseudo-directories.

## Sizes

| Tracks | Bytes | With error bytes |
|---|---|---|
| 80 | 819,200 | 822,400 |

## Geometry

- **Tracks**: 80
- **Sectors per track**: 40 (uniform)
- **Bytes per sector**: 256
- **Directory track**: 40 (header at T40/S0, BAM at T40/S1 and T40/S2, dir chain from T40/S3)
- **Max root dir entries**: 296 (37 dir sectors × 8 entries)
- **File interleave**: 1 (the 1581 buffers a whole track in memory, so interleave-1 is fastest)
- **Dir interleave**: 1 for the same reason

## What you can do

Full read/write — directory operations, file imports, viewers, validate, BAM, sort, lock/unlock, splat, geos, REL records, etc.

### CBM sub-partitions

The 1581's firmware supports carving the disk into sub-areas it calls "partitions". They show up as file-type `$05` (CBM) in the directory, but if their size and placement match the spec rules they can be opened with `CD"name"` from BASIC and used as a sub-directory.

Spec rules from D81.TXT (lines 433-435):

1. Must start on sector 0 of a track
2. Size must be a multiple of 40 sectors (one whole track)
3. Minimum 120 sectors (3 tracks)
4. Must not include or cross track 40 (the root dir track)

The editor's **File → Add Directory** creates a partition that follows these rules. The prompt asks for the partition size in sectors (min 120, multiples of 40); you get exactly that size, no auto-rounding.

**Maximum 26 sub-partitions** of the minimum size — 13 on side A (tracks 1-39), 13 on side B (tracks 41-80), 1 leftover track. In practice you'll usually have a handful of larger partitions.

Sub-partitions can't nest. Within a sub-partition you can have files but not another partition. (This is a firmware limitation, not an editor one.)

### Pasting into a full sub-partition

If you paste files into a sub-partition that doesn't have enough free space, the editor offers a Cancel / **Grow** prompt with the exact shortfall in blocks and the proposed grow size. The grow extends the partition into adjacent free root tracks (if any). If no adjacent free tracks exist, the prompt tells you how short it is and skips the Grow option.

## Auto-boot loader

D81.TXT documents an auto-boot mechanism — if BAM byte `+$07` (at T40/S1) is non-zero, the 1581 ROM looks for a USR-typed file called `COPYRIGHT CBM 86` and runs it. The BAM viewer's banner flags this when present.

## Block count cap

Same 65,024 cap as D64 (VICE truncates higher values).

## Saving

Writes the natural 819,200 bytes (822,400 with errors).
