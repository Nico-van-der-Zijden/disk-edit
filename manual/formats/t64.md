# T64 — tape archive

T64 is a virtual tape archive used by CCS64 and other tape emulators. It's not a real tape image (TAP is, for that); it's a directory of programs in a tape-flavored container.

## Geometry

- Fixed 64-byte header (`C64S tape file`, `C64 tape image file`, etc.)
- Directory of variable size (usually 30 or 60 entries)
- Each entry: 32 bytes — filename, start address, end address, file offset

## What you can do

**Read-only.** Tape archives are uncommon to *create*; the editor reads existing ones.

You can:

- List the files
- View files as Hex / Disassembly / PETSCII / BASIC / Graphics / TASS
- Export individual files as `.prg`
- Extract everything to a new D64 via **Disk → Disk Tools → Extract to D64**

You cannot:

- Rename, delete, add files
- Edit the T64 directly

If you need to modify a T64, extract to D64, edit there, and re-create the T64 with another tool.

## Block count cap

Not applicable — T64 has no block counts in the C64-disk sense.
