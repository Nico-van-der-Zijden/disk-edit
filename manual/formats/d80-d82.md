# D80 / D82 — 8050 / 8250 IEEE-488 drives

D80 (Commodore 8050) and D82 (Commodore 8250) are IEEE-488 drives used with PETs and the C64 via an IEEE interface card. The format is similar to D64/D71 but with different geometry and a two-block BAM.

## Sizes

| Format | Tracks | Bytes | With error bytes |
|---|---|---|---|
| D80 (8050) | 77 | 533,248 | 535,331 |
| D82 (8250) | 154 | 1,066,496 | 1,070,662 |

## Geometry

- **Sectors per track** varies by zone (much like D64 but different boundaries)
- **Header track**: 39
- **Two BAM sectors**: T38/S0 covers tracks 1-50, T38/S3 covers tracks 51-77 (D80) or up through 154 (D82, with extra BAM blocks)
- **Default file + dir interleave**: 1 (the IEEE-488 ROM does whole-track buffering, so interleave-1 is fastest — D80-D82.TXT spec)

The D80/D82 BAM layout is more complex than D64's single-track BAM; the editor handles both per the spec.

## What you can do

Full read/write. The viewer renders both BAM blocks in the heat map. Validate rebuilds both BAM sectors.

## Saving

Writes the natural size.

## Known quirks

- D82 disks are large (1 MiB) and uncommon. If you have one, it'll open and edit normally, but you may not have many sister tools that can validate against it.
- A few D80 disks in the wild use `$01` as the DOS-version byte (soft write-protect). Use **Disk Tools → Restore DOS Version Byte** to clear it.
